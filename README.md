IL2CPP metadata generated by [Il2CppInspectorPro](https://github.com/jadis0x/Il2CppInspectorPro) fork by jadis0x, disassembly+pseudocode generated by [IDA Pro](https://hex-rays.com/ida-pro), and are put together by some personal scripts.<br>
The input libil2cpp binary was taken from [APKMirror](https://www.apkmirror.com/apk/505-games-srl/terraria/terraria-1-4-5-6-4-release/terraria-1-4-5-6-4-android-apk-download/).<br>
This site includes:

- Function disassembly
- File and function metadata
- C-like pseudocode derived from the disassembly (limited to <16KB functions)
- <s>Xref graph</s> (disabled because it looks ugly atm)
- Type definitions

Function documentations are under <code>dasm/</code> and grouped based on their namespace.<br>
Type documentations are under <code>types/</code> and grouped based on an alphabetical index of their first 2 letters.<br>
All function documentations go under .c file documentation pages. Likewise, all type documentations go under .h files.

For type definitions, some types have special IL2CPP types alongside it that means different things:

- <code>__Boxed</code>: boxed form of a value type (Il2CppObject header + value/fields)
- <code>__Array</code>: array object (Il2CppObject header + bounds, max_length, vector of elements)
- <code>__Fields</code>: helper struct holding instance fields for MSVC-style inheritance
- <code>__VTable</code>: virtual-method table struct (MethodInfo* or VirtualInvokeData entries)
- <code>__StaticFields</code>: struct holding the type's static fields
- <code>__Class</code>: Il2CppClass-shaped metadata struct for the type
- <code>__Enum</code>: C enum representation for a C# enum (uses underlying integral type)

Stats: ~141079 functions, 85071 types. Self-hosted with [nginx](https://nginx.org) and [ngrok](https://ngrok.com) tunnel.<br>
